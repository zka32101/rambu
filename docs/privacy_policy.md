# プライバシーポリシー

**最終更新日**: 2026-08-27  
**施行日**: 2026-09-01

---

## 1. はじめに

本プライバシーポリシー（以下「本ポリシー」）は、乱舞将棋（以下「本アプリ」）の利用者（以下「ユーザー」）の個人情報の取扱いについて、その収集、利用、管理、保護に関する方針を定めるものです。

本アプリを利用することで、本ポリシーの内容に同意したものとみなします。

---

## 2. 収集する情報

### 2.1 自動収集される情報

本アプリの利用に伴い、以下の情報が自動的に収集されます：

#### 2.1.1 デバイス情報
- デバイス識別子（UUID）
- OS 名とバージョン
- デバイスモデル
- 画面解像度
- タイムゾーン・言語設定

#### 2.1.2 ゲーム関連イベント
- ゲーム開始・終了時刻
- 対局結果（勝敗）
- 着手数（ターン数）
- 選択した難易度
- ハイライト動画の生成成功/失敗
- SNS シェアの実行有無

#### 2.1.3 Firebase Analytics イベント
- セッション開始・終了
- スクリーンビュー
- ボタンクリック
- 機能使用時間

#### 2.1.4 エラー・クラッシュ情報
- クラッシュスタックトレース
- エラーメッセージ
- 発生時刻
- 発生時のゲーム状態

### 2.2 ユーザーが明示的に提供する情報

- ユーザー名（オプション）
- メールアドレス（オプション・お問い合わせ時）

### 2.3 第三者から取得する情報

- なし

## 3. 情報の利用目的

収集した個人情報は、以下の目的でのみ利用されます：

### 3.1 基本的な目的

- **アプリの提供・改善**
  - ゲーム機能の正常動作確認
  - UI/UX の最適化
  - バグ修正・パフォーマンス改善

- **ユーザーサポート**
  - エラー報告への対応
  - ユーザー問い合わせへの回答（メール提供時）

### 3.2 分析・統計目的

- **利用パターン分析**
  - DAU（日次アクティブユーザー数）
  - セッション時間分析
  - 機能別使用率

- **ゲームバランス分析**
  - AI の勝率分析
  - 難易度別の遊戯時間

- **ハイライト機能の分析**
  - 生成成功率
  - シェア率
  - ユーザー体験 (UX) 改善

### 3.3 禁止される利用目的

以下の目的での利用は、絶対に行いません：

- ❌ ユーザーへの追跡・監視
- ❌ 他社製品・サービスの宣伝・広告配信
- ❌ 個人情報の第三者への販売
- ❌ 行動ターゲティング広告の配信
- ❌ 個人識別情報（PII）と非個人識別情報の結合による追跡

## 4. 情報の第三者提供

### 4.1 提供先

本アプリは、以下の第三者サービスと情報を共有します：

#### Google Firebase
- **サービス**: Cloud Firestore, Analytics, Cloud Storage, Authentication
- **送信データ**: ゲームイベント、エラーログ、デバイス ID
- **通信**: 暗号化（TLS 1.3）
- **Google のプライバシーポリシー**: https://policies.google.com/privacy

#### Bitly
- **サービス**: URL 短縮
- **送信データ**: ハイライト動画の URL（個人識別情報なし）
- **通信**: 暗号化（HTTPS）
- **Bitly のプライバシーポリシー**: https://bitly.com/pages/privacy

### 4.2 提供しない情報

以下の情報は、いかなる第三者にも提供されません：

- ユーザー名
- メールアドレス
- 位置情報
- 連絡先情報
- 支払い情報

### 4.3 法的根拠に基づく開示

以下の場合、本ポリシーに関わらず、法的要求に応じて情報を開示する場合があります：

- 裁判所の令状
- 検察からの捜査協力要請
- 日本法の法的義務

## 5. データの保保持・削除

### 5.1 保持期間

| データ | 保持期間 | 管理者 |
|--------|---------|--------|
| Firebase Analytics | 14 ヶ月（自動削除） | Google |
| ハイライト動画 | 30 日（自動削除） | Cloud Storage |
| Firestore ゲームログ | ユーザー削除まで | 弊社 |
| クラッシュレポート | 90 日 | Firebase Crashlytics |

### 5.2 データの削除

#### ユーザーによる削除
1. 本アプリの「設定」→「アカウント削除」を実行
2. 確認メッセージに同意
3. 全データが Firestore から削除
4. 30日以内に関連ファイルも削除

#### 管理者による削除
- 利用規約違反者のアカウント削除
- 法的要求に基づく削除

#### 自動削除
- Analytics: 14 ヶ月後に自動削除
- ハイライト: 30 日後に自動削除
- Crashlytics: 90 日後に自動削除

## 6. データセキュリティ

### 6.1 実装されているセキュリティ対策

- **転送時の暗号化**
  - TLS 1.3（全通信）
  - HTTPS（Firebase）

- **保存時の暗号化**
  - Google Cloud Platform による自動暗号化
  - Cloud Storage: AES-256
  - Firestore: Google が管理

- **アクセス制御**
  - Firebase Authentication（認証ユーザーのみアクセス可能）
  - Firestore Security Rules（権限ベースのアクセス制限）
  - API キーの環境変数管理（コードに含めない）

### 6.2 セキュリティルール例

```
// Firestore Security Rules
match /users/{userId} {
  allow read, write: if request.auth.uid == userId;
}

match /games/{gameId} {
  allow read: if true;  // 公開
  allow write: if request.auth.uid == resource.data.playerId;
}

// Cloud Storage
match /highlights/{userId}/{allPaths=**} {
  allow read, write: if request.auth.uid == userId;
}
```

### 6.3 セキュリティインシデント対応

セキュリティ上の問題が発生した場合：
1. **検知**: Crashlytics・ログ監視で即座に検知
2. **評価**: 重要度・影響範囲を評価
3. **対応**: 緊急アップデートをリリース
4. **通知**: 必要に応じてユーザーに通知
5. **事後対応**: ログ解析・原因究明

**報告先**: security@rambusgame.jp

## 7. ユーザーの権利と選択

### 7.1 アクセス権

ユーザーは、弊社が保有する自身の個人情報にアクセスする権利があります。

**手続き**: support@rambusgame.jp に「データアクセス要求」とメール

### 7.2 修正・削除権

ユーザーは、自身の個人情報の修正・削除を要求できます。

**手続き**:
1. アプリ内「設定」→「プロフィール編集」で自身の情報を修正
2. 「アカウント削除」で全データを削除

### 7.3 拒否権

- **Cookie/トラッキング**: 本アプリは Cookie を使用しません
- **Analytics**: Firebase Analytics は拒否できませんが、個人識別情報は送信されません
- **位置情報**: 本アプリは位置情報を要求しません

## 9. GDPR コンプライアンス（EU ユーザー向け）

### 9.1 適用範囲

欧州経済領域（EEA）のユーザーには、GDPR が適用されます。

### 9.2 法的根拠（Legal Basis）

- **Legitimate Interests**: ゲーム機能改善・サポート
- **Consent**: オプション機能（ユーザー名登録など）

### 9.3 データ処理者

- Primary: 本アプリ開発者
- Sub-processors: Google Firebase, Bitly

### 9.4 ユーザー権利

GDPR に基づく権利：

- **Access Right**: 個人データへのアクセス
- **Rectification**: データの修正
- **Erasure**: 「右を忘れられる権利」
- **Portability**: データの移植
- **Objection**: 処理への異議

**手続き**: support@rambusgame.jp に「GDPR Request」

### 10.1 適用範囲

カリフォルニア州のユーザーには、CCPA が適用される場合があります。
