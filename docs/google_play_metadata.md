**Full Description (4000文字以内)**

```
⚔️ 将棋を知らない視聴者でも「うわ、今の一撃やばい」で盛り上がる —

乱舞将棋は、本将棋に「HP制」と「飛び道具」を組み合わせた、全く新しい観戦映え特化の将棋バリアントです。

【ゲームの特徴】

🎮 シンプルなルール
・9×9の盤面で本将棋と同じ駒を配置
・駒にHP（ヒットポイント）を付与
・相手の王のHP を0にしたら勝ち
・戦いは「静かな読み合い」から「殴り合いの爽快感」へ進化

⚡ クリティカルアタック
・角・飛などの飛び道具には「射程」と「冷却時間」を設定
・遠隔から相手の駒を狙撃できる
・着弾時のエフェクト + 画面シェイク + SE で爽快感MAX

🤖 AI対戦
・3段階の難易度（初級・中級・上級）
・CPUが常に50%の勝率で戦う
・バランスが取れた対局 = 観戦が面白い

📱 ハイライト動画共有
・対局終了後、自動でハイライト動画を生成
・クリティカル・大ダメージ・逆転のシーンのみを抽出
・Bitly による短縮URL で SNS（Twitter・TikTok・Instagram）で瞬時にシェア
・配信・切り抜き文化に完全対応

【なぜ観戦映えするのか】

将棋は深い読み合いが魅力ですが、視聴者には「何が起きているのか」がわかりません。
乱舞将棋は：

✓ HP ゲージで「敵がどれだけ危ないのか」が一目瞭然
✓ 飛び道具で一撃で形勢が変わる　→ 「えっ、逆転！」
✓ クリティカル演出で盛り上がる瞬間が可視化される
✓ 15秒ハイライトで配信・SNS 拡散が簡単

【今すぐダウンロード】

・無料で何局でも遊べる
・スキマ時間で5分ゲーム
・AI と対戦（通信不要）
・ハイライト動画のシェアで友達と共有

乱舞将棋で、新しい将棋体験を始めよう。

【サポート】

ご質問・ご不具合は以下までお気軽にお問い合わせください：
support@rambusgame.jp

【プライバシーポリシー】

https://rambusgame.jp/privacy

【利用規約】

https://rambusgame.jp/terms
```
